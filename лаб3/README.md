# Лабораторная работа №3

## Тема
Системы контроля версий Git.

## Вариант
Вариант 9. Анализ цен на рынке первичного жилья в России за последние 15 лет.

## Описание проекта
Приложение разработано на языке C# с использованием Windows Forms. Программа загружает данные из CSV-файла, отображает их в таблице, строит графики изменения цен, выполняет анализ изменения стоимости квартир и строит прогноз методом скользящей средней.

## Используемые технологии
- C#
- Windows Forms
- Chart
- CSV
- Git
- GitHub

## Структура веток
- main — итоговая стабильная версия проекта;
- dev — общая ветка разработки;
- nastya — загрузка данных и таблица;
- dev1 — построение графиков;
- dev2 — анализ и прогнозирование.

## Реализованные функции
- загрузка данных из файла;
- вывод данных в таблицу;
- построение интерактивных графиков;
- анализ изменения цен;
- прогнозирование методом скользящей средней;
- экспорт графика в PNG.

## Авторство
Работа выполнена индивидуально с имитацией командной разработки.
