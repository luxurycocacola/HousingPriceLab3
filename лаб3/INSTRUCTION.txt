КАК ОТКРЫТЬ ПРОЕКТ

1. Распакуй архив HousingPriceLab3.zip.
2. Открой Visual Studio 2022.
3. Нажми "Открыть проект или решение".
4. Выбери файл HousingPriceLab3.sln.
5. Нажми Ctrl+F5 или зеленую кнопку "Пуск".
6. В программе сначала нажми "Загрузить данные".
7. Потом проверь кнопки: "Построить графики", "Анализ изменения цен", "Построить прогноз", "Экспорт графика PNG".

ЕСЛИ ПРОЕКТ НЕ ОТКРЫЛСЯ

1. Создай новый проект Windows Forms App (.NET Framework) с названием HousingPriceLab3.
2. Закрой Visual Studio.
3. Из архива скопируй в папку проекта все файлы из папки HousingPriceLab3/HousingPriceLab3:
   Form1.cs
   Form1.Designer.cs
   HousingData.cs
   IDataLoader.cs
   CsvHousingLoader.cs
   ForecastService.cs
   GraphExportService.cs
   housing_prices.csv
4. Открой проект снова.
5. Если Visual Studio попросит перезагрузить проект — согласись.
6. Запусти.

ЧТО СКРИНШОТИТЬ ДЛЯ ОТЧЕТА

1. Главное окно программы.
2. Таблицу после нажатия "Загрузить данные".

4. Окно анализа после нажатия "Анализ изменения цен".
5. Прогноз после нажатия "Построить прогноз".
6. Сохранение графика через "Экспорт графика PNG".
